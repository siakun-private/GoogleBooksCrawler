# Google Play Books 로컬 EPUB 추출

새 세션은 [AGENTS.md](AGENTS.md)와 [인수인계 시작점](docs/handoff.md)을 먼저 읽습니다. 추출 구조, 뷰어 설계, 검증과 문제 해결 문서는 이 시작점에서 연결합니다.

Orca에서 로그인해 열어 둔 Google Play Books 책을 XHTML, 이미지와 글꼴로 저장하고, 목차가 있는 EPUB으로 묶습니다. 본문은 검색하거나 복사할 수 있는 텍스트로 보존합니다. 이미지는 서버가 반환한 파일을 다시 압축하지 않고 저장합니다.

Windows, Python 3.12 이상, 실행 중인 Orca가 필요합니다. 이 디렉터리에서 필요한 Python 패키지를 설치합니다.

```powershell
python -m pip install -r requirements.txt
```

Orca에 대상 책을 열고 본문이 표시된 상태에서 실행합니다. `--book-id`에는 Google Play Books 주소의 `id` 값을 넣습니다. 같은 책을 여러 탭에 열었거나 다른 자동화가 같은 탭을 제어하면 먼저 하나로 정리합니다.

```powershell
python -X utf8 extract.py --book-id x6puEAAAQBAJ
```

이미 추출한 결과가 있거나 작업을 중단했다면 `--resume`으로 이어서 실행합니다. 다른 판본이나 별도 사본을 저장하려면 `--output`으로 새 디렉터리를 지정합니다.

```powershell
python -X utf8 extract.py --book-id x6puEAAAQBAJ --resume
```

EPUB은 `output`에 책 제목으로 저장됩니다. `output/content/index.html`을 브라우저에서 열면 인터넷 연결이나 별도 서버 없이 본문을 읽을 수 있습니다. 본문의 외부 참고 링크는 해당 사이트에 접속합니다.

HTML 읽기 화면의 상단에서 표시 옵션, 목차, 북마크와 본문 검색을 엽니다. 표시 옵션에는 어두운 테마, 글꼴, 글꼴 크기, 행 간격, 정렬과 한 페이지 또는 두 페이지 레이아웃이 있습니다. 자동 레이아웃은 창이 넓으면 두 페이지로 표시합니다. 설정, 북마크와 읽던 위치는 같은 브라우저의 로컬 저장소에 남습니다. 브라우저가 저장소 사용을 허용하지 않으면 창을 닫은 뒤 복원되지 않습니다.

하단에는 현재 화면에 보이는 원본 페이지 범위를 표시합니다. 슬라이더와 페이지 번호 입력으로 원본 페이지에 이동합니다. 화살표, 좌우 방향키, Page Up/Down, 마우스 휠은 화면 분량만큼 넘깁니다. 글꼴이나 창 크기에 따라 한 원본 페이지가 여러 화면에 걸칠 수 있으므로 넘길 때마다 원본 페이지 번호가 바뀌지는 않습니다. 터치 화면에서는 좌우로 밀어 넘깁니다.

읽기 화면만 다시 만들려면 다음 명령을 실행합니다. 다른 컴퓨터로 옮길 때는 이미지와 글꼴이 함께 있는 `content` 폴더 전체를 복사합니다.

```powershell
python -X utf8 html_reader.py output/content/book.json
```

추출을 반복하지 않고 저장한 자료만 EPUB으로 다시 묶으려면 다음 명령을 실행합니다. 이 단계에는 Orca나 로그인이 필요하지 않습니다.

```powershell
python -X utf8 build_epub.py output/content/book.json --output 'output/면접을 위한 CS 전공지식 노트.epub'
```

추출기는 뷰어의 전체 구간 목록을 따라 이동하고 페이지로 자르기 전의 본문을 읽습니다. Orca CLI로 선택한 탭의 로컬 디버깅 연결을 찾으며, 별도 로그인 정보나 쿠키 파일을 만들지 않습니다. 추출 후 읽던 위치로 돌아갑니다. Google 뷰어의 내부 구조가 바뀌면 본문을 조각내어 대신 저장하지 않고 오류로 중단합니다.

저장한 본문 글자 수와 원본 페이지 앵커를 대조합니다. 패키징 단계에서는 XHTML/XML 구조, 목차와 각주의 대상, 이미지와 CSS의 로컬 참조를 검사합니다. 추출 결과의 개수, 이미지 크기와 해시는 `output/capture-report.json`에서 확인합니다. EPUBCheck를 별도로 실행했다면 검사 결과는 `output/epubcheck-report.json`에서 확인합니다. 구조 검증은 모든 EPUB 앱의 화면 모양이 같다는 보장을 대신하지 않습니다.

이미지를 크게 요청했을 때 픽셀 수가 늘어나는 것만으로 화질 개선을 판단하지 않습니다. 기본 추출은 뷰어가 본문에 지정한 이미지 주소를 사용하며, 스크린샷의 해상도나 디스플레이 배율에 좌우되지 않습니다.

```powershell
python -X utf8 -m unittest -v test_export.py
```

`output`은 로컬 산출물 디렉터리이며 Git 추적에서 제외합니다.
