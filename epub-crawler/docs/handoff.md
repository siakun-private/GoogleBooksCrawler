# 새 세션에서 이어가기

저장된 책을 고치거나 뷰어를 개발하는 작업은 재수집부터 시작하지 않습니다. 이 폴더의 `output/content/book.json`이 로컬 자료의 진입점이고 `output/content/index.html`이 생성한 읽기 화면입니다. `output`이 없는 체크아웃에서는 수집한 책이 Git에 포함되지 않은 정상 상태일 수 있습니다.

## 시작 순서

1. 저장소 상태와 이 폴더의 [AGENTS.md](../AGENTS.md)를 확인합니다. 사용자 변경을 분리하고 현재 작업이 추출, 패키징, 뷰어 중 어디에 속하는지 정합니다.
2. [README](../README.md)의 설치와 실행 명령을 읽습니다. 책 식별자와 제목은 `output/content/book.json`, 추출 완료 여부는 `output/capture-report.json`과 `output/capture-state.json`에서 확인합니다.
3. [검증 절차](validation.md)로 저장된 자료를 확인합니다. `output/handoff-state.json`이 있으면 로컬 이동 및 검증의 마지막 기록을 참고하되 현재 탭이나 포트로 재사용하지 않습니다.
4. 변경할 영역에 따라 [추출 구조](extraction.md), [HTML 뷰어](reader.md), [문제 해결](troubleshooting.md)을 읽습니다. 코드의 해당 함수와 문서를 함께 고칩니다.

## 산출물과 근거

| 확인할 내용 | 원천 |
| --- | --- |
| 구간 순서, 목차, 페이지 앵커, 표지와 책 정보 | `output/content/book.json` |
| 재개할 판본과 완료된 구간 | `output/capture-state.json` |
| 원본 글자 수, 누락 앵커, 자산 크기와 해시 | `output/capture-report.json` |
| EPUB 규격 검사 결과 | `output/epubcheck-report.json` |
| 로컬 HTML의 기능과 본문 검사 | `output/reader-verification.json`, `output/reader-content-verification.json`, 새 검사 보고서 |
| 이동 전후 보존 검사 | 저장소 루트 `.local`의 이동 보고서 |

이 보고서는 생성 당시의 입력을 검증한 기록입니다. 오래된 요약의 테스트 개수를 문서에 옮기거나 새 실행 결과로 오인하지 않습니다. 수정 후의 근거는 새 검사 보고서로 남깁니다.

## 보존할 설계 판단

화면의 페이지 조각에는 문단과 코드가 잘려 있거나 다시 열린 태그가 들어갑니다. 수집기는 리더가 갖고 있는 분할 전 구간을 읽어 문장을 보존합니다. 이미지와 글꼴도 화면 캡처가 아니라 브라우저가 읽는 리소스의 바이트를 저장합니다. 화질 개선은 픽셀 수 증가와 실제 세부 정보 증가를 구분합니다.

HTML은 Google Books와 유사한 표시 옵션, 계층 목차, 북마크, 검색과 하단 이동 막대를 제공합니다. 글꼴 크기를 바꿔도 원본 페이지 앵커를 탐색 기준으로 유지합니다. 한 화면에 여러 원본 페이지가 보이면 `5–6 / 444`처럼 범위를 표시합니다. 이 수치는 UI 형식의 예이며 책의 실제 총수는 메타데이터에서 읽습니다.

추출과 오프라인 재생성을 나눴으므로 로그인 없이 EPUB과 뷰어를 고칠 수 있습니다. 에이전트에 반복 조작을 맡겨도 완료 보고만 믿지 않고 파일과 검증 결과를 확인합니다. 종료된 작업자의 터미널 ID나 디버깅 포트는 다음 세션에 넘길 실행 정보가 아닙니다.

## 재현 범위와 남은 확인

캡처한 판본의 성공이 다른 책이나 변경된 Google 리더 내부 구조를 보장하지는 않습니다. 코드에 저장된 메타데이터 구조, DOM 선택자, 이미지 형식 허용 목록이 맞는지 새 대상에서 확인합니다. 특히 추출기는 WebP를 인식하지만 EPUB 패키저의 MIME 목록에는 WebP가 없으므로 해당 입력은 현재 검증 단계에서 거부됩니다. 자동 재압축으로 조용히 우회하지 않습니다.

`file://`의 localStorage 보존 범위는 브라우저와 파일 위치에 따라 다를 수 있습니다. 폴더 이동 후 책 자체는 상대 경로로 열리지만 설정과 북마크가 자동 이전됐다고 가정하지 않습니다. `output/reader-state.json`이 있으면 해당 책의 UI 상태를 옮길 때만 사용하며 인증 정보와 혼동하지 않습니다.
