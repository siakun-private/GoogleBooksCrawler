# 이미지 크롤러 작업 지침

작업 전 [README](README.md), [운영 안내](docs/operations.md), [구조와 주의점](docs/architecture.md)을 읽습니다. 이 폴더는 페이지 이미지와 PDF 파이프라인이며 형제 폴더의 EPUB 추출기와 다른 브라우저를 사용합니다.

`gui_app.py`와 `modules`가 GUI 실행 경로입니다. `Source`는 직접 실행하는 노트북과 실험 자료이며 이름에 test가 있어도 자동 회귀 검사로 취급하지 않습니다. 노트북은 Chrome 실행, 외부 사이트 접속, 파일 쓰기를 포함하므로 일괄 실행하지 않습니다.

이 폴더를 현재 작업 디렉터리로 삼습니다. `settings.ini`와 `chrome_profile`은 사용자의 상태이므로 초기화하거나 버전 관리하지 않습니다. 로그인 문제를 이유로 프로필을 지우지 않습니다.

기존 런타임 파일은 이전 설치 경로에 묶여 있습니다. 새 환경은 `.venv`와 `requirements.txt`로 만듭니다. 환경 파일 이동과 크롤러 기능 변경을 섞지 않습니다.

이미지 변환과 번호 재정렬은 파일을 덮어쓸 수 있습니다. 검증에는 임시 복사본을 사용합니다. 원본 자산 보존이 필요한 EPUB 작업에 선명도, 색상 보정이나 JPEG 재압축을 적용하지 않습니다.

변경 후에는 Python 구문과 모듈 import를 확인하고 변경한 이미지 처리 경로만 임시 자료로 실행합니다. 로그인된 실제 책의 전체 재수집은 경로 정리만으로 필요한 검사가 아닙니다.
