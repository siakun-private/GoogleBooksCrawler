# 구조와 보존할 동작

GUI는 Tkinter에서 설정과 작업을 연결하며 장시간 작업은 별도 스레드에서 실행합니다. `modules/settings_manager.py`가 INI를 관리하고 `modules/scraper.py`가 Selenium 세션을 소유합니다. 실행 경로의 원천은 GUI의 import와 각 작업 메서드입니다.

## 수집

수집기는 별도 Chrome 프로필로 로그인 상태를 유지합니다. iframe 안의 가상 스크롤 목록에서 `reader-rendered-page`의 이미지를 찾고 이미 본 URL은 건너뜁니다. 마지막 항목을 스크롤해 다음 페이지를 요청합니다. 선택자와 URL 중복 검사 방식은 현재 코드에 정의돼 있으며 다른 리더 형식에도 적용된다고 가정하지 않습니다.

이미지 다운로드는 브라우저 안에서 `fetch`한 Blob을 임시 다운로드 링크로 저장합니다. 파일명을 `.png`로 붙여도 응답의 실제 형식이 PNG라는 보장은 없습니다. URL을 수집 목록에 넣는 시점과 디스크 저장이 끝나는 시점도 다릅니다. 다운로드가 실패한 URL이 이미 수집 목록에 남을 수 있으므로 완전성 보장이 필요한 개선은 디스크의 결과까지 확인해야 합니다.

줌 기능은 `document.body.style.zoom`을 바꿉니다. 고해상도 원본을 받았는지는 저장 파일의 크기와 실제 세부 정보로 확인합니다. 화면 배율을 키운 사실만으로 화질 향상을 보고하지 않습니다.

## 이미지 처리

변환기는 Pillow를 사용합니다. PNG 변환은 동일한 이름의 기존 PNG를 덮어쓸 수 있습니다. JPEG와 PDF는 RGB 처리를 수행하며 선명도와 색상 보정의 기본값은 `modules/image_converter.py`에서 읽습니다. GUI의 선택적인 보정과 원본 보존을 구분합니다.

번호 정리는 숫자와 소수점이 있는 이름을 자연 정렬한 뒤 임시 이름과 최종 이름으로 두 번 변경합니다. 기존 `temp_` 이름과 충돌하거나 중간에 파일 이동이 실패하면 부분 변경이 남을 수 있습니다. 성공 로그만 보지 말고 실제 파일 목록을 확인합니다.

PDF 생성기는 PNG 입력 이미지를 메모리에 모으므로 큰 책은 메모리를 많이 사용합니다. 손상 파일을 허용하는 Pillow 설정과 개별 예외 후 계속 진행하는 동작 때문에 출력 파일 존재만으로 원본 보존이나 완전성을 판단하지 않습니다.

## 변경 범위

설치 환경을 재생성하는 일과 수집 알고리즘을 바꾸는 일을 나눕니다. 현재 저장된 브라우저 프로필과 사용자 INI는 재현용 기본값이 아닙니다. 오래된 노트북 안의 URL과 절대 경로도 다른 사용자의 환경에 그대로 적용하지 않습니다.
